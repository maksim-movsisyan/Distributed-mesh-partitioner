# Block Mesh Generator Design Contracts & Conventions

This document formalizes the topological, geometric, and numerical specifications required for the block-structured unstructured mesh generator module. The resulting grid is written to a standard CGNS file containing one base and one unstructured zone (`ZoneType_t = Unstructured`).

---

## 1. Global Coordinate System and Indexing

* **Coordinate Frame:** 3D Right-Handed Cartesian coordinate system $(x, y, z)$.
* **Units:** All input coordinates are multiplied by the global scalar `scale` to convert them to SI meters ($m$).
* **Indexing in Configuration:** All vertex indices in the input file are 0-based.
* **Indexing in CGNS Output:** All node indices, element ranges, and section connectivity arrays are strictly 1-based (CGNS SIDS compliance).

---

## 2. Macro-Block Ordering Contract (`HEXA_8`)

Each macro-block is defined by 8 corner vertices: `[v0, v1, v2, v3, v4, v5, v6, v7]`. The ordering adheres strictly to the **CGNS SIDS / VTK_HEXAHEDRON** specification:

* `[v0, v1, v2, v3]` define the bottom face ($\zeta = 0$), ordered counter-clockwise when viewed from above (looking in the $-\zeta$ direction).
* `[v4, v5, v6, v7]` define the top face ($\zeta = 1$), following the identical relative rotational order.

```text
   v7 ---------- v6
  /|            /|
 / |           / |
v4 ---------- v5 |
|  |          |  |
|  v3 --------|- v2
| /           | /
|/            |/
v0 ---------- v1
```

### Parametric Coordinate Axes and Right-Hand Rule
The local curvilinear coordinate system $(\xi, \eta, \zeta) \in [0, 1]^3$ is spanned by:
* $\vec{\xi} = \vec{v}_1 - \vec{v}_0$ (Direction of local index $i \in [0, N_x]$)
* $\vec{\eta} = \vec{v}_3 - \vec{v}_0$ (Direction of local index $j \in [0, N_y]$)
* $\vec{\zeta} = \vec{v}_4 - \vec{v}_0$ (Direction of local index $k \in [0, N_z]$)

**Positive Jacobian Invariant:**
Every block must strictly form a right-handed basis:
$$(\vec{\xi} \times \vec{\eta}) \cdot \vec{\zeta} > 0$$
Blocks with negative or zero Jacobians are rejected during config parsing.

---

## 3. Macro-Face Ordering Contract (`QUAD_4`)

Every boundary patch is constructed from planar four-node macro-faces: `[f0, f1, f2, f3]`.

### Outward Normal Invariant
The vertices of each boundary face must be ordered such that the cross-product of edge vectors points **strictly outward** from the computational domain:
$$\vec{n} = (\vec{f}_1 - \vec{f}_0) \times (\vec{f}_3 - \vec{f}_0), \quad \vec{n} \cdot \vec{n}_{\text{outward}} > 0$$

When viewed from outside the domain looking towards the interior, the sequence $f_0 \to f_1 \to f_2 \to f_3$ proceeds in a counter-clockwise direction.

---

## 4. Block Interface Conformance Contract

Adjacent blocks sharing a common macro-face must maintain topological conformality:
1. **Geometric Match:** The four vertices of the interface face must coincide geometrically between the two blocks.
2. **Resolution Match:** The number of cells along the shared directions must be identical ($N_{\text{shared}, 1}^{(A)} = N_{\text{shared}, 1}^{(B)}$ and $N_{\text{shared}, 2}^{(A)} = N_{\text{shared}, 2}^{(B)}$).
3. **Grading Match:** If non-uniform clustering is applied along a shared edge or face, the grading formulation and stretching parameter must match along the shared interface to prevent non-matching nodes.
4. **Node Merging:** Internal boundary nodes generated by neighboring blocks are reconciled into a single global Node ID using spatial hashing with absolute tolerance:
   $$\varepsilon = 10^{-7} \cdot L_{\min}$$

---

## 5. 2.5D Extrusion Contract

For quasi-2D CFD simulations:
1. The third coordinate axis is conventionally aligned with $Z$.
2. The number of cells across the thickness is set to one ($N_z = 1$).
3. The front plane ($z = z_{\min}$) and back plane ($z = z_{\max}$) must be explicitly assigned to a boundary section (e.g., `symmetry` or `empty`) to close the dual graph for the partitioner.

---

## 6. Grid Stretching and Grading Formulations

For each local parametric direction, normalized coordinate $s = \frac{i}{N} \in [0, 1]$ is mapped to physical parametric space $\xi \in [0, 1]$.

### Available Grading Types

#### 1. `uniform`
Equal grid cell distribution:
$$\xi(s) = s$$

#### 2. `geometric` (Power Law Expansion)
Grading ratio $r = \frac{\Delta s_{\text{end}}}{\Delta s_{\text{start}}}$:
* If $r = 1.0$: $\xi(s) = s$
* If $r \neq 1.0$:
  $$\xi(s) = \frac{1 - r^s}{1 - r}$$
  *(For discrete cell steps, $\Delta s_{k} = \Delta s_0 \cdot \alpha^k$ where $\alpha^{N-1} = r$).*

#### 3. `tanh_start` (Boundary Layer at $s = 0$)
Hyperbolic tangent clustering concentrated at the start of the interval ($s = 0$):
$$\xi(s) = 1.0 - \frac{\tanh\left(\delta \cdot (1.0 - s)\right)}{\tanh(\delta)}$$
where $\delta > 0$ is the stretching intensity parameter (`grading`).

#### 4. `tanh_end` (Boundary Layer at $s = 1$)
Hyperbolic tangent clustering concentrated at the end of the interval ($s = 1$):
$$\xi(s) = \frac{\tanh(\delta \cdot s)}{\tanh(\delta)}$$

#### 5. `tanh_both` (Double Boundary Layer at $s = 0$ and $s = 1$)
Symmetric clustering towards both opposing boundaries (channel walls), coarse in the center ($s = 0.5$):
$$\xi(s) = \frac{1}{2} \left[ 1.0 + \frac{\tanh\left(\delta \cdot (2s - 1.0)\right)}{\tanh(\delta)} \right]$$

---

## 7. Transfinite Interpolation (TFI)

Inside each block, 3D coordinates for indices $(i, j, k)$ corresponding to parametric coordinates $(\xi, \eta, \zeta)$ are computed via trilinear volume interpolation:

$$\vec{X}(\xi, \eta, \zeta) = \sum_{p=0}^1 \sum_{q=0}^1 \sum_{r=0}^1 N_{pqr}(\xi, \eta, \zeta) \cdot \vec{P}_{pqr}$$

where shape functions are defined as:
$$N_{pqr}(\xi, \eta, \zeta) = \left[(1-p) + (2p-1)\xi\right] \cdot \left[(1-q) + (2q-1)\eta\right] \cdot \left[(1-r) + (2r-1)\zeta\right]$$

and $\vec{P}_{pqr}$ are the 8 Cartesian corner coordinates of the macro-block.

---

## 8. CGNS Output Structure Contract

The generated output is an unstructured CGNS file containing:
* **Base:** `Base_3D` (CellDimension = 3, PhysicalDimension = 3)
* **Zone:** Single unstructured zone `Zone_1` (`ZoneType_t = Unstructured`)
  * `VertexSize` = Total number of unique merged nodes ($N_{\text{nodes}}$)
  * `CellSize` = Total number of volume elements ($N_{\text{cells}}$)
  * `BndVertexSize` = 0
* **Coordinates:** `CoordinateX`, `CoordinateY`, `CoordinateZ` under `GridCoordinates`
* **Section 1 (Volumetric):**
  * Type: `HEXA_8`
  * Element Range: `[1, N_cells]`
  * Connectivity: Array of size $8 \times N_{\text{cells}}$
* **Sections 2 to M+1 (Boundaries):**
  * Type: `QUAD_4`
  * Element Range: Continuous range `[N_cells + 1, N_cells + N_bnd]` partitioned sequentially across all specified boundary patches.
  * Section Names: Matching the `name` attribute specified in `[[boundaries]]`.
